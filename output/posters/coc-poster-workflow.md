# CoC 模组宣传海报工作流程（免外部依赖版）

本流程用于在仓库内**直接产出可发布海报文件**，无需额外安装图片库。

## 1) 输入信息模板

每次先确定以下字段：

- 模组名：`永恒恶意（Malice Everlasting）`
- 规则：`克苏鲁的呼唤 CoC 7版`
- 人数：`3-5人`
- 时长：`3-5次团，每次约3-4小时`
- 形式：`线上语音 + 骰点机器人`
- 风格关键词：`调查 / 悬疑 / 克苏鲁恐怖`
- KP 名称：`Lucius`
- 报名方式：`私信：角色概念 + 可开团时间`

## 2) 文案分层

海报文案按三层组织：

1. **吸引层（标题）**：
   - `克苏鲁TRPG` 
   - `《永恒恶意》`
   - `招募玩家 PL`
2. **信息层（规则与玩法）**：
   - 系统、人数、时长、形式、风格
3. **行动层（CTA）**：
   - `有兴趣请私信报名：角色概念 + 可开团时间`
   - `KP：Lucius`

## 3) 视觉规范（CoC 氛围）

- 画幅：`1080 x 1620`（社群常用竖版）
- 背景：深蓝/墨绿暗色渐变
- 点缀：微弱光晕、雾感、旧纸色边框
- 可读性：文字对比度优先，避免过度花纹遮挡

## 4) 输出格式

- 主文件：`SVG`（可直接预览、可后续导出 PNG）
- 命名：`output/posters/<module>-recruit-poster.svg`

## 5) 质量检查清单

- 是否包含：模组名、系统、人数、时长、形式、报名方式、KP 名称
- 中文是否无错别字
- 标题是否在移动端可读
- 深色背景下正文是否清晰
