# CoC 模组宣传海报工作流程（专业发布版）

本流程用于在仓库内稳定产出具有专业感的 CoC 宣传海报（可直接预览/发布）。

## 1) 输入信息模板（必须完整）

- 模组名：`永恒恶意（Malice Everlasting）`
- 规则：`克苏鲁的呼唤 CoC 7版`
- 人数：`3-5人`
- 开团预估耗时：`共4次团，每次约3.5-4小时`
- 开团地点：`上海市虹口区吴淞路258号耀江发展中心A栋7楼701`
- 风格关键词：`调查 / 悬疑 / 克苏鲁恐怖 / 电影感`
- KP 名称：`白羽`
- 报名方式：`私信：角色概念 + 可参与时间段`

## 2) 文案信息架构

1. **主标题层（抓眼）**：
   - `《永恒恶意》`
   - `招募玩家 PL`
2. **内容层（决定转化）**：
   - 系统、类型、人数、耗时、地点
3. **行动层（CTA）**：
   - 报名方式 + KP 名称

## 3) 视觉设计规范（CoC 专业感）

- 画幅：`1080 x 1620`（移动端竖版）
- 结构：`标题区 / 信息卡区 / 报名CTA区`
- 背景氛围：深蓝黑主色 + 月光冷高光 + 雾层 + 城市剪影
- 版式原则：高对比可读性、统一间距、重点信息加框
- 风格定位：电影海报质感，避免廉价花哨特效

## 4) 输出产物

- 示例海报：`output/posters/yongheng-eyi-recruit-poster.svg`
- 提示词文件：`output/posters/yongheng-eyi-gpt-image2-prompt.md`

## 5) 发布前检查

- [ ] KP 名称是否为“白羽”
- [ ] 是否包含“开团预估耗时”
- [ ] 是否包含完整线下地点
- [ ] 字体尺寸在手机端是否可读
- [ ] 背景是否符合 CoC 氛围并保持专业感
