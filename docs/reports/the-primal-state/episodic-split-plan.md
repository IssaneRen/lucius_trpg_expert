# 原初之境：商团 6~8 小时分集方案

目标：把《原初之境》拆成适合商团流动人数的短单元。每一集都要有明确玩家动机、局部胜利、可跑场景、主线保留线索和结尾画面。

## 团队评审结论

本轮使用 `team-leader-work` 方式并行评审。

- 挑剔玩家评审：旧版满意度 74%，不通过。主要问题是目标抽象、玩家动机弱、阶段性胜利不足、第三和第四集像支线插播。
- 老手 GM 改造：建议改成 6 集版，每集 3~5 个场景，每集只解决一个局部问题。
- 证据校验：拆法能被 segment A/B/C/D/F/G/H 支持；segment E 已并入 C。湖区和奥拉夫营与巴尔家主线多为锚点和主题呼应，不是原文强因果。
- 文件迁移：主 PDF 已复制进工程内 `raw/`，catalog 不再依赖本机绝对路径。

## 证据边界

为了避免把 GM 改造写成原文事实，本文使用两类标记：

- 原文事实：来自已有 segment 报告，可以直接作为模组内容运行。
- GM 桥接：为了商团分集体验新增的连接方式，用来让支线更自然地通向主线。

## 推荐总结构

1. 墓地闹鬼与钟声
2. 枫糖店、生意与失踪女儿
3. 尚普兰湖、尸体与更大的网络
4. 大学、奥拉夫营与黑屋阴影
5. 回到巴尔家，地下室真相
6. 黑车复仇与最后代价

如果只想跑 5 次，第六集并入第五集最后 60~90 分钟。

## 商团通用规则

- 每集开场用 10 分钟证据板，只复盘上集 3 条证据。
- 缺席调查员默认在档案保管员 NPC 身边整理资料，下集带回一个线索。
- 人数不足时不裁证据，只裁路程、重复问询、第二战斗和旁支传说。
- 每集结尾必须做到：局部问题解决，但主线更黑。

## 第一集：墓地闹鬼与钟声

玩家动机：两块 18 世纪墓碑午夜移动，教会和警长都无法解释。调查员被报纸、私家侦探委托或本宁顿度假行程卷入。

吸引点：玩家不是单纯看鬼，而是在发现“旧封印被现代道路工程拆坏”。这是全战役主题的第一颗钉子：现代化正在破坏旧防护。

适配内容：`《邀请来舞会》`

可跑场景：

1. 报纸/委托开场：两块墓碑午夜移动，调查员抵达本宁顿。
2. 圣彼得教堂与墓地：墓碑无拖痕，第四根角柱被施工移除，钟声异常。
3. 旧档案调查：康斯坦丝审判、杰里迈亚受害、车琴猎魔人、鸣钟放逐术。
4. 施工队问询：工头、虚构工程师托尼·特拉利亚、道路改造与奈亚痕迹。
5. 午夜墓地/幻梦境：钟响十三下，见康斯坦丝与七角星记号。

阶段性目标和结局：

- 目标：查明墓碑移动原因，并恢复或临时替代旧防护。
- 小胜利：恢复鸣钟放逐术，或暂时驱散康斯坦丝。
- 阶段结局：本宁顿墓地安静下来，但调查员知道本地旧防护正在被拆。

保留 3 个证据：

- 第四根防护角柱被道路施工移除。
- 康斯坦丝左胸下方七角星巫术记号。
- 教堂记录里的鸣钟放逐术与旧女巫审判。

主线连接：

- 原文事实：康斯坦丝是莉莉丝信徒；巴尔家主线也涉及莉莉丝和巫术崇拜。
- GM 桥接：用“莉莉丝 / 旧巫术 / 旧防护被破坏”的主题把第一集自然引向巴尔家，不把墓地案写成巴尔家直接作案。

人数不齐裁剪：

- 2~3 人：删施工队长时间盘问，直接让牧师提供诉讼文件。
- 4~5 人：保留钟楼护送、墓地诱敌、档案翻译三线分工。
- 临时缺席：缺席者在教堂整理记录，下集带来保纳尔/枫糖商店入口。

结尾镜头：

清晨钟声重新响起，墓碑不再移动。施工队留下的图纸上，下一段道路正穿过保纳尔附近一片旧林地。

关键线索补发：

- 如果玩家不查教堂档案，麦肯齐牧师会在结尾交出诉讼文件，里面有角柱和鸣钟放逐术记录。
- 如果玩家不追施工队，钟楼修复后，警长会带来道路图纸，提示下一段工程靠近保纳尔旧地界。

证据来源：segment A、segment B、segment H。

## 第二集：枫糖店、生意与失踪女儿

玩家动机：克莱儿的枫糖小生意被玛格莉特新店吞掉，她开始做噩梦，树木发病，电话里出现奇怪声音。玩家需要救一个活人，而不只是查旧案。

吸引点：这是“乡村商业竞争”逐渐变成“家庭邪教恐怖”的一集。玩家能看见玛格莉特如何用现代商店、电话、补给和舆论吃掉克莱儿的生活。

适配内容：`《树汁持续流淌》前半`

可跑场景：

1. 克莱儿家：传统枫糖小农、树病、噩梦、经济压力。
2. 玛格莉特新店：低价红色枫糖、旅游商品、过度友善、电话/补给控制。
3. 密大与幽灵女学生线索：艾蜜莉没有正常入学，只有撤回申请。
4. 黑车民俗/多德森证词：雨夜女学生、推车、惨叫、头颅失踪。
5. 夜间守树或尾随：克莱儿梦中描述的蹄印意象、树病、异常树汁气味；若想加速推进，可作为 GM 桥接提前投放远处的艾蜜莉亚身影。

阶段性目标和结局：

- 目标：证明克莱儿不是妄想，巴尔家确实在用异常手段压垮她。
- 小胜利：拆穿电话监听，或拿到密大撤回申请信，或守树确认树病和异常树汁不是克莱儿妄想。
- 阶段结局：玩家确认巴尔家生意、艾蜜莉失踪、异常枫糖之间有联系，但地下室真相暂不揭开。

保留 3 个证据：

- 密大无艾蜜莉入学记录，只有玛格莉特撤回申请。
- 红色、低价、味道异常好的枫糖。
- 幽灵女学生事件与艾蜜莉死亡方式吻合。

主线连接：

- 原文事实：玛格莉特隐瞒艾蜜莉死亡，艾蜜莉亚并非正常人，异常枫糖和克莱儿遭遇是主线压力。
- 修正旧版问题：本集不提前开放《莉莉丝抄本》、无头遗骸和后树林浅坟。这些留到第五集。
- GM 桥接：如果玩家很快锁定巴尔家，可提前给“远处有人影站在林边”或“疑似偶蹄印被雨水冲淡”的轻量暗示，但不要提前给后树林浅坟和地下室证据。

人数不齐裁剪：

- 2~3 人：密大调查改成电报/电话结果，不跑远程资料戏。
- 4~5 人：一组查密大，一组查多德森，一组探店。
- 临时缺席：缺席者做化验或查校档，下集带回“无异常但太好吃”的枫糖报告。

结尾镜头：

克莱儿家的电话第一次响起。她接起后脸色发白，因为听筒另一端不是人声，而是车轮陷进泥里的湿响。

关键线索补发：

- 如果玩家不查密大，克莱儿会拿出玛格莉特曾炫耀过的大学信封，促使玩家发电报核实。
- 如果玩家不碰电话线，电话公司工人或克莱儿邻居会抱怨两户共线，暴露监听入口。

可借鉴结构：`Dead Light` 的路边孤立追猎感，但黑车只作为艾蜜莉死亡回声，不抢主线。

证据来源：segment C、segment G。

## 第三集：尚普兰湖、尸体与更大的网络

玩家动机：第二集后，克莱儿线索暂时卡死：她害怕、玛格莉特装作无辜，直接闯巴尔家证据不足。此时伯灵顿验尸官辛克莱请求协助，湖边尸体案出现雨夜、失踪者和旧家族传闻等相似质感，罗伯特·巴尔又正好能提供水流线索和巴尔家族外部证词。

吸引点：这集不再只是“换口味查湖怪”，而是给玩家一个可选但强推荐的后续补证资源：罗伯特·巴尔这个外部家族证人，以及阿伯纳西/大学线入口。湖区案本身可结，但它的功能是把调查从“克莱儿 vs 玛格莉特”推向“巴尔家旧事存在外部核对入口”。

适配内容：`《尚普兰湖的怪兽》`

推荐固定版本：

- 使用“新月献祭 + 孤岩角黑石祭坛 + 萨默斯/邪教线”作为主版本。
- 湖怪和尚普传说保留为误导和氛围，不作为最终解释。

可跑场景：

1. 伯灵顿验尸官办公室：辛克莱展示尸检照片，尸体周期接近新月。
2. 码头与罗伯特·巴尔：水流、漂尸范围、巴尔家族时间线闲笔。
3. 佛蒙特大学咨询：黑石祭坛、尚普、茲维波古亚、普鲁登斯传说。
4. 孤岩角搜索：湿滑步道、水下黑石祭坛、蹼趾/蹄印痕迹。
5. 新月夜监视：萨默斯、邪教徒、湖怪误导或献祭现场登场。

阶段性目标和结局：

- 目标：阻止下一次新月献祭，确认尸体来源。
- 小胜利：破坏一次献祭、揭出萨默斯，或确认水下祭坛存在。
- 阶段结局：湖区案子能结，玩家同时获得罗伯特这个后续补证入口。水下祭坛和巴尔家地下结构只作为主题呼应，不写成同一组织。

保留 3 个证据：

- 尸体出现周期与新月吻合。
- 水流反推落水点指向孤岩角。
- 水下黑石祭坛刻有神话文字。

主线连接：

- 原文事实：罗伯特·巴尔是后续巴尔家调查锚点；阿伯纳西可连接第四集。
- GM 桥接：罗伯特可以提到“玛格莉特搬走后，我再没见过她那个年纪不对的女儿”，把玩家推向第五集身份补证。不要让他说玛格莉特调查过黑石，避免把湖区邪教误写成巴尔家同谋。

人数不齐裁剪：

- 2~3 人：只保留萨默斯邪教首领版本，删四真相并列。
- 4~5 人：保留湖怪误导、大学研究、码头监视三线。
- 临时缺席：缺席者留在大学翻译祭坛文字，下集带出阿伯纳西/奥拉夫营入口。

结尾镜头：

祭坛被破坏后，湖面短暂平静。罗伯特·巴尔盯着水说：“你们要是真在查玛格莉特，就别只听她自己说她有几个女儿。”这是 GM 桥接台词，用来提示罗伯特可作为后续核对玛格莉特家庭说法的入口。

关键线索补发：

- 如果玩家不找罗伯特，辛克莱会把“码头管理员熟悉巴尔家旧事”写在验尸补充意见里。
- 如果玩家不查大学，祭坛拓片会被辛克莱转交给大学同事，回信直接引出阿伯纳西和奥拉夫营。

可借鉴结构：`The Lightless Beacon` 的孤立地点和外部怪物压力，但湖怪只做压力，不改写主线真相。

证据来源：segment D、segment H。

## 第四集：大学、奥拉夫营与黑屋阴影

玩家动机：佛蒙特大学考古队失联，且大学回信表明阿伯纳西正在研究“会把人绑定在地点上的古老结构”。第三集祭坛拓片或第四集开头的大学回信上，出现了和巴尔家旧地界/后续莉莉丝符号同形但不相同的“地点绑定”记号。玩家不去奥拉夫营也能继续主线，但会缺少理解地下仪式空间的工具。

吸引点：这集的乐趣不是“又查一堆资料”，而是进入一个被诅咒的考古营地，在食人、活死人、日志和符文之间找出逃离规则。它给玩家一种明确回报：带回能识别仪式空间和地点绑定诅咒的知识。

适配内容：`《家，甜蜜的家》`

6~8 小时裁剪原则：

- 保留：大学失联导入、格莉妮丝住所、奥拉夫营、死者证词、nid 竿/阴影规则。
- 降级为背景或备援：完整挖掘、冰岛远程研究、长期生存资源管理、过多 NPC 往返。

可跑场景：

1. 佛蒙特大学导入：阿伯纳西考古队、搜寻者失联。
2. 格莉妮丝住所：手稿、《萨迦》、星象图、冰岛档案。
3. 奥拉夫营抵达：迷路、营地腐败、麦克道格持枪食人。
4. 死者证词：拉克、肢解但不死的阿伯纳西、游荡的布赖德。
5. 土丘与 nid 竿：日志、符文、黑屋阴影，选择欺骗或破坏诅咒。

阶段性目标和结局：

- 目标：找到失联考古队，并弄懂营地为什么困住所有人。
- 小胜利：救出至少一名仍可作证的人，或带回阿伯纳西日志/符文翻译；理想结果是骗过黑屋阴影并带回可用于第五集的反制知识。
- 阶段结局：玩家理解“阴影、家屋、古老语言、献祭结构”如何绑定人和地点。

保留 3 个证据：

- 阿伯纳西日志里的符文抄录。
- “黑屋的阴影 / nid 竿阴影”翻译。
- 土丘顶部结构不是普通遗址，而是诅咒装置。

主线连接：

- 原文事实：F 支持古诺斯语、nid 竿、阴影诅咒、土丘结构。
- GM 桥接：玩家可把“阴影绑定地点”的知识用于第五集识别巴尔家地下室不是普通地下室，而是仪式空间。这个桥是主题和方法上的连接，不是原文强因果；银护符仍应从第五集的《奇术异事》/树汁材料取得。

人数不齐裁剪：

- 2~3 人：删完整生存资源管理，只保留一次饥饿/疾病压力和一次布赖德袭击。
- 4~5 人：保留营地内部分工：守夜、翻译、挖掘、诱敌。
- 临时缺席：缺席者留在大学或格莉妮丝处查资料，下集带来“仪式空间识别”和“符号翻译”帮助；银护符入口留给第五集。

结尾镜头：

众人逃出森林时，太阳从土丘背后升起。阴影离开他们脚边，但其中一人的影子慢了半拍才跟上。

关键线索补发：

- 如果玩家不进格莉妮丝住所，大学同事会把她留下的手稿和星象图交给调查员。
- 如果玩家不翻译符文，阿伯纳西或拉克会用断续证词说出“不是屋子，是屋子的影子困住我们”。

可借鉴结构：`Edge of Darkness` 的旧仪式地点和规则理解，但这里的重点是逃离和理解，不是完整驱魔。

证据来源：segment F、segment H。

## 第五集：回到巴尔家，地下室真相

玩家动机：克莱儿最后一次来电称“蹄印在玛格莉特院子里”。如果玩家不行动，克莱儿会死或精神崩溃，巴尔家也会处理证据。

吸引点：前四集的线索终于汇到一个屋子里。玩家不是“突然搜屋”，而是带着密大记录、黑车线索、罗伯特证词、符号知识和银护符制作线索准备进门。

适配内容：`《树汁持续流淌》第四部分`

可跑场景：

1. 幽灵女学生再现：黑车、无头尸体、偶蹄印、硫磺味。
2. 伯灵顿补证：波默罗伊旧居证词、罗伯特确认没有 25 岁女儿艾蜜莉亚。
3. 克莱儿最后电话：蹄印在玛格莉特院子里；可救援或发现遗嘱/保险箱。
4. 巴尔家宅搜查：储藏室活板门、艾蜜莉旧卧室、干净书房、地下肮脏书房。
5. 后树林与地下神殿：无头遗骸、《莉莉丝抄本》、浅坟、红色汁液、艾蜜莉亚真容。

阶段性目标和结局：

- 目标：进入巴尔家，确认艾蜜莉死亡和艾蜜莉亚来源。
- 小胜利：找到艾蜜莉无头遗骸和《莉莉丝抄本》，证明玛格莉特误杀并召来莉莉丝之子。
- 阶段结局：完整真相成立，玩家必须选择最终处置方向：报警、烧毁证据、追杀母女、尝试交易、保护克莱儿，或守在魔鬼弯道等待黑车来临。

保留 3 个证据：

- 艾蜜莉无头遗骸。
- 《莉莉丝抄本》。
- 后树林浅坟、红色树汁与偶蹄印。

前四集回收清单：

- 第一集：莉莉丝信徒、旧封印、七角星记号。GM 桥接效果是让玩家接受后续仍可能出现莉莉丝/旧巫术主题。
- 第二集：密大记录、幽灵女学生、异常枫糖，直接指向艾蜜莉死亡和巴尔家作案。
