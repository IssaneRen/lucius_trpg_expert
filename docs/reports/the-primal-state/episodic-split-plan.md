# 原初之境：6~8 小时分集拆分方案

目标：把《原初之境》拆成适合商团流动人数的短单元。每一集都要有明确阶段目标、局部结局、可回收线索，并尽量把主线真相分批释放。

## 先验结论

- 这套模组完全可以拆成多个 6~8 小时单元。
- 最稳的做法不是“把四个支线硬切开”，而是把它们当成独立剧集，再用《树汁持续流淌》做主轴串起来。
- 每一集的结尾都要给出一种“我现在知道更多了，但还没完全知道”的收束感。

## 推荐总结构

1. 序章引导
2. 本宁顿墓地事件
3. 巴尔家与枫糖主线
4. 尚普兰湖支线
5. 佛蒙特大学 / 奥拉夫营支线
6. 回到巴尔家与最终追逐

## 分集方案

### 第一集：墓地闹鬼与本地传闻

适配内容：
- 《邀请来舞会》
- 少量本地介绍与巴尔家铺垫

本集目标：
- 让玩家认识本宁顿地区的异常
- 找到“这不是普通闹鬼”的证据
- 让玩家第一次接触康斯坦丝女巫、钟声驱逐术、墓碑移动等核心意象

阶段结局：
- 玩家确认墓地事件与某个古老诅咒有关
- 至少拿到一条通往巴尔家或当地教会档案的硬线索
- 本集可以在“放逐成功 / 见到真相幻象 / 封住一处异常”处收尾

要保留的主线线索：
- 康斯坦丝和钟声驱逐术
- 本地旧案和异教痕迹
- 巴尔家或枫糖商店的关联入口

### 第二集：枫糖、生意与失踪的女儿

适配内容：
- 《树汁持续流淌》前半

本集目标：
- 让玩家看懂玛格莉特如何用商业、电话、补给和舆论吞掉克莱儿的生活
- 明确艾蜜莉并不“只是人”
- 让玩家第一次接近“家族悲剧其实是邪教结构”

阶段结局：
- 玩家发现巴尔家的异常生意与失踪女儿之间有明确联系
- 玩家拿到《莉莉丝抄本》、无头遗骸、后树林浅坟、红色树汁等至少两类关键证据
- 本集结尾应停在“真相快露出来了，但屋子里还有东西没被点破”

要保留的主线线索：
- 玛格莉特误杀与掩盖
- 艾蜜莉亚的真实属性
- 电话监听、商店异常、树汁污染

### 第三集：社区崩坏与湖面异象

适配内容：
- 《尚普兰湖的怪兽》
- 作为主线压力外溢的一集

本集目标：
- 让玩家感到外部世界也在变坏，而不只是巴尔家一户出事
- 用湖怪、尸体、谣言或邪教献祭，把“异常不是单点”说透
- 让玩家意识到有人或有物正在把整个地区当成资源场

阶段结局：
- 玩家确认湖区事件至少和一条邪教/古神/连环杀手线相关
- 至少拿到一个可以回扣主线的实证，不只是传闻
- 这集结束时，玩家应该知道“更大的东西还在后面”

要保留的主线线索：
- 湖区异常并非孤立
- 可回扣萨默斯 / 普鲁登斯 / 邪教献祭等版本化真相
- 让巴尔家案子与更大的黑暗网络产生联系

### 第四集：大学、营地与禁忌知识

适配内容：
- 《家，甜蜜的家》

本集目标：
- 把调查从城镇推进到知识和地形层面
- 让玩家通过奥拉夫营、大学档案、黑屋诅咒、nid 竿，摸到“古老结构本身就在维持邪恶”
- 给玩家一个可收束的独立冒险结尾

阶段结局：
- 玩家完成营地求生或诅咒破解
- 玩家拿到能解释主线一部分的知识文本或符号
- 结尾最好是“活着回来，但已经被盯上”

要保留的主线线索：
- 黑屋 / nid 竿 / 阴影诅咒
- 古老语言、仪式和家族结构的对应关系
- 与巴尔家地下结构的遥相呼应

### 第五集：回到巴尔家，收束主线

适配内容：
- 《树汁持续流淌》后半与结局

本集目标：
- 把前面所有线索回收
- 直面巴尔家宅、地下室、后树林、红色树汁和黑车复仇
- 给出一个明确胜负结果

阶段结局：
- 消灭或驱逐玛格莉特与艾蜜莉亚
- 处理黑车复仇或魔鬼弯道追逐
- 明确本案的代价和后果

要保留的主线线索：
- 莉莉丝抄本
- 无头遗骸
- 后树林浅坟
- 红色树汁与偶蹄印

## 推荐切分原则

- 每集只保留一个核心目标，不要同时塞两个主线高潮
- 支线优先作为“换口味”或“缓冲段”，不要抢主线最终解释权
- 如果人数不齐，优先删跑图和重复问询，保留能产出新信息的节点
- 每一集至少留 1 条通向下一集的硬线索，最好留 2 条

## 给后续模型的继续工作点

- 进一步把每集细化成 3~5 个场景
- 为每集补“玩家可能跳过某场景时的替代入口”
- 标出每集最该保留的 3 个证据
- 为人数不足的情况做裁剪版
- 给每集补一个可直接拿来跑的结尾镜头
