## 摘要

《家，甜蜜的家》是格拉斯腾伯里/奥拉夫营长篇冒险。佛蒙特大学考古队失联，调查员前往奥拉夫营，发现营地受奥拉夫改造的 nid 竿/“黑屋阴影”诅咒影响。核心解法不是硬拆遗址，而是挖掘、翻译并理解“阴影”条件，解除或欺骗诅咒。

## 节点

- N1 佛蒙特大学导入：阿伯纳西教授、麦克道格、布赖德失联，搜寻者艾咪·拉克也失联。
- N2 格莉妮丝住所：手稿副本、《萨迦》、冰岛旅行、星象图、雷克雅维克档案馆线索。
- N3 前往奥拉夫营：7 号国道、保纳尔、格拉斯腾伯里、徒步进山。
- N4 营地/麦克道格：偏执、持枪、食人，承认队伍死亡碎片。
- N5 生存压力：食物、水、卫生、疾病、昆虫、同类相食。进入并开始居住/扎营后会被诅咒束缚；此前返程受导航惩罚和绕路异象影响，但并非绝对不能离开。
- N6 拉克出现：最初不知道自己已死，仍可沟通，是最可能讲述事发经过的人。
- N7 阿伯纳西出现：被肢解但不死，想复仇，是关键翻译资源。
- N8 布赖德出现：活死人威胁，残虐且不可谈判，会主动游荡、嘲弄、伏击并重复折磨目标。
- N9 日志/遗迹：主帐篷有日志、铭文抄录、未译《奥拉夫·乌尔夫森萨迦》。
- N10 土丘/黑屋：阿布纳基遗址覆盖在更古老的多重黑暗遗址之上；奥拉夫把土丘整体改造成 nid 竿。
- N11 挖掘顶部广场：暴露古诺斯语铭文，理解诅咒。完整挖掘约需 120 人工作日，五人队加一名考古学家约 40 天。
- N12 格莉妮丝现身：推进救援/冲突，可提供手稿、冰岛线索和有限语言辅助，但不能替代准确翻译。
- N13 外部研究：佛蒙特大学、阿布纳基故事、维京资料、雷克雅维克档案。
- N14 解除诅咒：暴力破坏 nid 竿/顶部符文与马头镶嵌结构，或移动/重定向土丘阴影。
- N15 逃离：成功离开奥拉夫营。

## 关键 NPC / 力量

- 丹尼尔·阿伯纳西：考古教授，被麦克道格肢解但因诅咒不死。
- 格莉妮丝·阿伯纳西：妻子，语言学背景，掌握手稿与冰岛线索，但古诺斯语能力有限。
- 詹姆斯·麦克道格：研究生，偏执、持枪、食人。
- 凯文·布赖德：研究生，活死人，主要肉体威胁。
- 艾咪·拉克：搜寻者，关键证人。
- 奥拉夫·乌尔夫森：约千年前冰岛恶棍兼巫师，建立“黑屋”并设置 nid 竿诅咒。
- 阿布纳基人：曾驱逐奥拉夫，后被诅咒困住。
- 敌对力量：nid 竿诅咒、营地、昆虫、饥饿、疾病、复活活死人。复活并非绝对无条件，头部严重损毁等例外需单独裁定。

## 线索链

- 大学失联 -> 考古队和搜寻者都消失 -> 去格莉妮丝或奥拉夫营。
- 阿伯纳西研究维京/阿布纳基遗址 -> 目标不是普通遗址 -> 进山。
- 手稿/《萨迦》 -> 奥拉夫、黑屋、nid 竿有关 -> 查营地文本。
- 麦克道格食人和承认死亡 -> 队伍内爆且死亡未结束 -> 找拉克/阿伯纳西/布赖德。
- 拉克证词 -> 麦克道格袭击队伍，阿伯纳西发现土丘人工结构和诅咒 -> 查土丘/日志。
- 阿伯纳西日志 -> 铭文和挖掘是关键 -> 暴露顶部广场。
- 正确翻译“黑屋的阴影 / nid 竿阴影” -> 诅咒绑定阴影 -> 可欺骗诅咒。
- 暴力破坏 nid 竿/顶部结构 -> 解除诅咒但触发 20D6 魔法死亡冲击 -> 优先欺骗阴影。

## 结局

- 摧毁 nid 竿/顶部诅咒结构：解除诅咒，但对诅咒区域内或附近每个人造成 20D6 魔法死亡冲击；爆炸区外或幸存的受诅咒僵尸会因维生诅咒被破坏而倒下、化为烂泥。
- 欺骗诅咒：通过巨大光源、改变土丘/营地地形等方式让营地不再处于土丘阴影，从而逃离。
- 成功逃离奖励 2D4+2 理智；杀死布赖德额外 1D8 理智。

## 卡点

- 不去大学：用格莉妮丝、熟人引荐或大学委托。
- 不知道地点：大学同事、格莉妮丝、阿伯纳西车辆、当地人指路。
- 想立即离开：扎营前并非绝对不能离开，但返程受 -50% 导航和绕路异象影响；成为受诅咒“居住者”后，离开阴影范围只能维持几分钟，被强行带走也会返回。
- 无法翻译：关键翻译资源是阿伯纳西、外部传讯/研究，或复活研究生的浅薄古诺斯语；格莉妮丝只能有限辅助。
- 暴力破坏 nid 竿/顶部结构：提示 20D6 死亡冲击波与复活者维持机制。
- 挖掘太慢：完整挖掘约需 120 人工作日；用布赖德袭扰、格莉妮丝到来和资源压力推进。
