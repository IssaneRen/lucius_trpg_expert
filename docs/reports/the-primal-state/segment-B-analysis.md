## 摘要

《邀请来舞会》是本宁顿圣彼得教堂墓地闹鬼冒险。核心结构是：报纸/委托进入本宁顿，调查墓碑移动与道路施工破坏角柱，查教堂旧记录得知康斯坦丝女巫与鸣钟放逐术，午夜进入墓地/幻梦境取得巫术记号。恢复鸣钟放逐术主要是恢复墓地防护、限制她影响；在幻梦境避难所杀死她才是永久死亡；在幻梦境中的本宁顿“杀死”通常只驱散到下一个午夜。

## 节点

- N1 报纸/导入：两块 18 世纪墓碑在午夜移动并叠放。
- N2 本宁顿镇：旅馆、圣彼得教堂、墓地、警长与本地传言。
- N3 墓地调查：无拖痕、无脚印；第四根防护角柱被道路施工移除。
- N4 掘墓：原墓位无尸体；现墓碑下有两具相拥骨骸，康斯坦丝颈骨断裂。
- N5 教堂旧记录：康斯坦丝审判、杰里迈亚受害、猎魔人车琴、鸣钟放逐术。
- N6 道路施工队：工头约翰·菲利普斯、虚构工程师托尼·特拉利亚、Nyarlathotep 变位词。
- N7 午夜墓地/幻梦境：钟响 13 下，杰里迈亚求救，康斯坦丝攻击。
- N8 解决：查看康斯坦丝左胸下方七角星记号，恢复鸣钟放逐术，或在幻梦境中杀死/驱散她。

## 关键 NPC

- 康斯坦丝·杰弗里斯：1789 年被处死的莉莉丝信徒女巫，死后继续折磨杰里迈亚。
- 杰里迈亚·沐恩：康斯坦丝受害者，幻梦境中求救。
- 诺伯特·麦肯齐牧师：提供教堂记录入口。
- 马丁·哈德森警长：警方代表。
- 齐比格尼尔·车琴：猎魔人，建立鸣钟放逐术。
- 约翰·菲利普斯：施工队工头。
- 托尼·特拉利亚：不存在的工程师，名字是奈亚拉托提普变位词。

## 线索链

- 墓碑移动且无人目击 -> 不是普通恶作剧 -> 调查墓地。
- 教堂钟声特殊声学消失 + 道路施工同期 -> 施工破坏防护 -> 查角柱/施工队。
- 角柱符号 + 旧记录 -> 康斯坦丝被封印 -> 需要恢复鸣钟放逐术。
- 法术需要康斯坦丝巫术记号 -> 午夜面对康斯坦丝或进入幻梦境 -> 看到七角星。
- 图书馆/神秘学典籍可识别角柱防护、女巫骑人飞行传说、钟声克女巫与鸣钟放逐术相似结构 -> 作为教堂记录之外的备用入口。
- 钟声可使康斯坦丝失能 -> 战术上敲钟争取查看记号/逃脱窗口，但钟楼路线会被康斯坦丝干扰。

## 风险和结局

- 康斯坦丝能让他人陷入昏睡、入梦、作祟、诅咒幸运、飞行、召唤夜魇/食尸鬼，并会偷听旅馆计划；重火力不可靠。
- 失败者可能灵魂被囚于幻梦境并持续理智损失。
- 成功恢复鸣钟放逐术或永久终结康斯坦丝后，每人奖励 1D10 理智。

## 卡点与备援

- 不去本宁顿：用报纸、记者/作家委派、私家侦探受邀、第三/第四次移动后雇佣、度假卷入、现代小报或土地征收诉讼推进。
- 远距离监视：调查员必然错过墓碑移动；摄影机会拍到一帧瞬移但无法解释，仍需进入墓地。
- 不愿午夜进墓地：麦肯齐牧师或胆大学童可替代触发，迫使调查员面对后果。
- 掘墓许可或挖错原墓位：牧师可被说服先在墓碑周边挖土；原墓位无尸体，现墓碑下才有两具骨骸。
- 不联想到施工：本地传言提到教堂钟声声学异常，且时间与道路施工吻合；牧师知道教区正在起诉施工方。
- 找不到隐藏记录：1789-1790 记录缺失、地下室松动石头、角柱相似符号、牧师开放旧档案都是入口。
- 不知道如何修复防护：教堂记录、图书馆和神秘学典籍共同指向鸣钟放逐术。
- 无法取得巫术记号：必须看到康斯坦丝左胸下方；可用钟声使她失能，或在幻梦境追踪她。
- 钟楼路线受阻：康斯坦丝会干扰敲钟，需安排护送、诱敌或分工。
