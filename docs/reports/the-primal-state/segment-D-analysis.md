## 摘要

《尚普兰湖的怪兽》是伯灵顿尸体/湖怪调查支线。验尸官辛克莱求助，调查连续“漂流物”尸体，反推孤岩角黑石祭坛，研究尚普、茲维波古亚与普鲁登斯·古德传说，最后根据守秘人选择的真相面对邪教、萨默斯、湖怪或连环杀手版本。

## 节点

- N0 伯灵顿验尸官办公室：辛克莱提供尸检、照片、过往记录。
- N1 伯灵顿码头/尚普兰湖：湖泊、水流、码头管理员罗伯特·巴尔。
- N2 孤岩角：野餐区、湿滑步道、陡崖、水下黑石祭坛。
- N3 佛蒙特大学：考古、历史、水流、神秘动物学咨询。
- N4 传说研究：普鲁登斯·古德、尚普、阿布纳基“上升湖水”、茲维波古亚。
- N5 警方/吉姆·萨默斯：关键不可信人物。
- N6 湖上调查/打捞/钓鱼：借船，可能短暂目击尚普。
- N7 新月夜监视/设陷阱：等待萨默斯、邪教徒、湖怪或祭祀出现。

## 关键 NPC / 怪物 / 组织

- 约翰·辛克莱医生：伯灵顿郡验尸官。
- 萝贝塔·欧克莱尔：最新受害者。
- 欧克莱尔先生：可能雇佣调查员。
- 小顽皮：受害者的狗，可帮助定位祭坛区域。
- 吉姆·萨默斯警探：根据版本可为邪教首领、连环杀手或利用湖怪的人。
- 罗伯特·巴尔：码头管理员，熟悉水流和传说，可借船。
- 丹尼尔·阿伯纳西博士：佛蒙特大学考古学家，关联《家，甜蜜的家》。
- 茲维波古亚信徒：约 12 人，认为献祭可防止伯灵顿遭洪水。
- 茲维波古亚：来自繁星的欢宴者，旧日支配者。
- 尚普/乔萨罗：湖怪，可解释为走鲸/械齿鲸类掠食者。
- 普鲁登斯·古德：1720 年女巫传说人物。

## 线索链

- 尸体每月约一次，日期吻合新月 -> 有周期性 -> 新月夜监视孤岩角。
- 尸体不是普通溺水或鱼啃食 -> 死因涉及大型掠食、工具或献祭 -> 查尸检/警方。
- 尸体在市码头以北固定范围冲上岸 -> 可反推落水点 -> 水流研究/罗伯特·巴尔。
- 佛蒙特大学/罗伯特·巴尔海图与水流分析 -> 孤岩角以南落水点 -> 搜索野餐区。
- 黑石祭坛有阿克洛语和茲维波古亚召唤文字 -> 神话仪式中心 -> 查典籍/邪教/萨默斯。
- 带蹼脚趾与蹄印足迹 -> 尚普/走鲸或误导线索 -> 湖怪研究。
- 辛克莱掌握的是萨默斯提供的二手警方案情，警方没有循线调查孤岩角 -> 萨默斯可疑 -> 监视萨默斯或查住所。

## 四种真相 / 结局

- 选项 1“照顾和餵食神明”：13 名本地人教团每月向茲维波古亚献祭，萨默斯是核心人物。
- 选项 2“亲爱的普鲁登斯”：普鲁登斯·古德/巨大黑蛇传说成为核心。
- 选项 3“乔萨罗/尚普”：湖中确有大型水陆两栖掠食者，可为走鲸/械齿鲸类。
- 选项 4“眨眼先生”：萨默斯是连环杀手；欧克莱尔夫人之死与萨默斯无关，真实死因保留悬疑；萨默斯另受祭坛声音影响。

破坏水底祭坛或消灭萨默斯可各恢复 1D6 理智。剧本建议不要让调查员明确杀死、捕获或清晰拍摄尚普，只保留模糊证据。

## 与主战役关系

- 可作为伯灵顿短篇侦探型支线。
- 罗伯特·巴尔是后续巴尔家/玛格莉特相关调查的锚点，会因调查嫂子谣言再次登场。
- 阿伯纳西博士关联《家，甜蜜的家》/奥拉夫营。
- 可连接北佛蒙特古老神秘力量、米-戈采矿和奥拉夫营线索。
