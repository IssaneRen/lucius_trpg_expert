## 摘要

《树汁持续流淌》第四部分是主线收束。调查员通过“幽灵女学生”、密大记录、伯灵顿证人、罗伯特·巴尔、克莱儿电话/死亡等线索回到巴尔家，在住宅、地下室和后树林发现艾蜜莉遗骸、《莉莉丝抄本》、受害者尸体、红色糖浆/汁液和偶蹄印，最终对抗玛格莉特与艾蜜莉亚。即使母女被消灭，仍有“魔鬼弯道”的黑车复仇追逐。

## 入口

- A：落单调查员夜间驾车经过克莱儿家附近，遇到“幽灵女学生”艾蜜莉；若不停，她会反复出现，并可能引入魔鬼弯道。
- B：经历幽灵女学生事件后，调查员可查密斯卡托尼克大学或伯灵顿。
- C：若仍不调查巴尔家，克莱儿会打电话尖叫“蹄印在玛格莉特院子里”，随后死亡，迫使调查员返回保纳尔。

## 节点

- N1 幽灵女学生：艾蜜莉自称住伯灵顿、正去密大；推车后被碾成无头尸身，留下偶蹄印和硫磺味。
- N2 调查玛格莉特：密大记录显示艾蜜莉二十年前中止入学，无正常入学记录。
- N3 伯灵顿/艾伦大道 33 号：乔治·波默罗伊证实玛格莉特曾独居经营糖果店，疑似高龄怀孕后卖房南下。
- N4 罗伯特·巴尔：确认玛格莉特没有名叫艾蜜莉亚的 25 岁女儿；艾蜜莉亚照片像年轻时的玛格莉特。
- N5 克莱儿死亡/未死：死亡则留下保险箱和遗嘱；未死则理智降至 20，恐惧黑车，仍相信玛格莉特是朋友，但认为艾蜜莉亚是女巫。
- N6 巴尔家宅：玛格莉特求饶、逃向树林或反抗；艾蜜莉亚会优先单独猎杀男性。
- N7 巴尔家关键房间：储藏室活板门、骨祭刀、艾蜜莉旧卧室、干净书房、地下室肮脏书房、莉莉丝神殿、艾蜜莉无头遗骸。
- N8 后树林：黑色马丁黄蜂、红色糖浆/汁液、受害者浅坟、偶蹄印。
- N9 《莉莉丝抄本》：记录玛格莉特误杀艾蜜莉、试图复活、召来莉莉丝之子艾蜜莉亚。
- N10 银护符：调查员根据《在新英格兰乐土上的奇术异事》制作并佩戴后生效，可免疫艾蜜莉亚迷惑男性，并看见真容。
- N11 魔鬼弯道：母女被消灭后，黑色轿车追逐调查员，物理手段无效，目标是制造高速车祸。
- N12 精神净化：按敌人是否被消灭、克莱儿是否获救、调查员是否零伤亡结算理智奖惩。

## 关键 NPC / 道具 / 地点

- 玛格莉特·巴尔：糖果商，艾蜜莉与艾蜜莉亚之母，持《莉莉丝抄本》。
- 艾蜜莉亚·巴尔：莉莉丝之子，半人黑山羊幼崽变种，能迷惑男性、吸取力量、发送梦境。
- 艾蜜莉·巴尔：二十年前死亡的无头幽灵，与黑色轿车相关。
- 克莱儿·杰普林：邻居老太太，可能死亡或精神崩溃。
- 罗伯特·巴尔：码头管理员，可提供家族时间线证词。
- 乔治·波默罗伊：伯灵顿书商，提供玛格莉特卖房和怀孕传闻。
- 道具：黑色马丁黄蜂轿车、人类大腿骨祭刀、艾蜜莉遗骸、腐烂泰迪熊、《莉莉丝抄本》、银护符、克莱儿保险箱/遗嘱、红色糖浆/汁液、时空门。

## 线索链

- 艾蜜莉自称去密大、住伯灵顿 -> 查密大与伯灵顿。
- 密大只有中止入学记录 -> 玛格莉特说法不实 -> 查玛格莉特旧居。
- 波默罗伊称玛格莉特疑似高龄怀孕并卖房南下 -> 艾蜜莉亚年龄与身份异常 -> 找罗伯特核对。
- 罗伯特确认没有 25 岁艾蜜莉亚，照片像年轻玛格莉特 -> 艾蜜莉亚不是正常女儿 -> 搜查巴尔家。
- 克莱儿电话提到蹄印在玛格莉特院子 -> 巴尔家与超自然痕迹直接关联 -> 进入巴尔家宅。
- 地下室艾蜜莉无头遗骸 + 《莉莉丝抄本》 -> 玛格莉特误杀艾蜜莉、召来莉莉丝之子 -> 真相成立。
- 《奇术异事》银护符 -> 免疫迷惑并见真容 -> 准备对抗艾蜜莉亚。

## 高潮 / 结局 / 失败后果

- 高潮地点：巴尔家宅、地下室与后树林。
- 关键操作时机：周日教堂时间与新月之夜是进入巴尔家的优选窗口；新月夜母女会通过地下室时空门去波士顿地区参加邪教活动。
- 艾蜜莉亚战术风险：她不睡觉，避免正面迎战复数调查员，会破坏调查员车辆，尤其可能往化油器灌枫糖浆。
- 证据核心：地下室神殿、《莉莉丝抄本》、艾蜜莉无头遗骸、后树林浅坟、黑色马丁黄蜂、红色糖浆/汁液、偶蹄印。
- 《莉莉丝抄本》快速阅读 revelations：玛格莉特与艾蜜莉之死有关；复活需要头颅；她联系莉莉丝获得新孩子；艾蜜莉亚快速成熟。
- 消灭玛格莉特与艾蜜莉亚后触发黑车复仇，进入魔鬼弯道追逐。
- 失败后果：调查员可能被艾蜜莉亚分割猎杀、吸干力量；罗伯特可能被杀；克莱儿死亡后房子被赎回夷平；黑车追逐可造成车祸、溺水、燃烧、刑事指控；被黑车杀死者会永远加入巴尔家黑车。
- 奖惩：消灭母女 +2D4 理智；玛格莉特逃走 -1D3；艾蜜莉亚逃走 -1D3，若知道真容再 -1D3；救下克莱儿 +1D3；零伤亡逃过复仇 +1D3。
